2. 프리팹
기존 Piece 프리팹, GoldRoot_Run 프리팹은 수정하거나 교체하지 않았다.
상인은 기존 Piece의 FieldAbsorbButtonRoot 하위 트리를 그대로 복제해 사용한다.
신규 상점·재화 프리팹을 별도로 만들지 않았다.

3. SpawnActor / Spine 연결
EventScene SpawnActor에 '상점주인' 여부 및 선택적인 Spine 프리팹 override를 추가했다.
기존 PieceData를 통한 시각물 생성과 Born/Idle, SpeechBubble 경로를 유지한다.
Event_Shop_FieldStage#1.asset의 기존 젤루상인 생성 스탭에만 상점주인 플래그를 켰다.
기존 위치·대사·스탭 순서는 유지했다. 상인은 EventSceneActor이며 전투 Piece/AI에 등록하지 않는다.
Spine override가 없으면 기존 PieceData의 시각 프리팹을 그대로 사용한다.

4. FieldAbsorbButtonRoot 재사용
EventScene ShopController에 기존 Piece 프리팹의 FieldAbsorbButton 참조를 연결했다.
상인 클릭 → 기존 Root 표시 → 판매 아이콘 클릭 → 같은 Root의 X로 취소.
기본 판매 아이콘은 기존 골드 아이콘, 취소는 기존 X 아이콘이다. Inspector에서 교체 가능하다.
판매 전용 콜백을 분리하고 일반 Piece의 기존 흡수 콜백은 유지했다.

5. sellPrice
BattleItemData.sellPrice: int, Inspector '판매 가격 (G)', Min(0).
실제 사용 시 SellPrice 속성에서 음수를 0으로 보정한다.
기존 데이터는 미설정 0을 유지한다. 0원 아이템은 판매되지 않는다.
구매 가격과 독립이다. 사용자 기획 가격을 임의로 입력하지 않았다.

일반 전투·월드맵 툴팁에서는 해당 문구를 숨긴다.

14. 카운팅 / Pulse
기본 카운팅0.5초(Inspector0.25~0.8), Ease Out, unscaledDeltaTime.
골드 숫자만 원래 Scale 기준 최대1.12배,0.25초 Pulse.
일반 골드 변경에서는 색상을 유지한다. 판매 미리보기에서만 초록색.
판매 보조 문구는0.9에서 약1.15 확대 후1.0 복귀, 종료 시 Fade Out/축소.
실제 골드가 연속 변경되면 현재 표시값에서 새 목표로 이어진다.
씬 최초 진입 및 재활성화는 현재 실제 골드를 즉시 표시한다.
비활성화 시 구독·카운팅·Pulse를 정리하고 원래 색상/Scale을 복구한다.

자동 Play Mode는 실제 씬과 UI 컴포넌트를 사용하지만 사람의 마우스/터치 수동 플레이와 동일하지 않다.

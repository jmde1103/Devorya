7. UI 배치 수정: 최종 방식이 중요
첫 단계에서는 마무리 흡수 버튼을 능력 버튼 왼쪽 아래로 상대 배치했습니다.
그 뒤 사용자 요청에 따라 기존 고정 anchor/inset 자동 배치를 대체하는 '씬에서 편집한 배치 사용' 모드를 추가했습니다.
최종 모드에서는:
- 씬에서 대상 UI 위치/크기를 직접 편집합니다.
- 씬 저장 또는 플레이 진입 직전에 SceneUILayoutAuthoring이 현재 배치를 자동 기록합니다.
- 실행 시 UI 중심의 화면 내 상대 위치를 유지합니다.
- 화면 밖으로 나가면 안쪽으로 보정하고 화면보다 큰 묶음은 축소합니다.
- 이전 anchor/inset/relativeTo/relativeOffset은 새 모드에서 사용하지 않습니다.
- BattleScene, BattleScenePVP, WorldMapScene, EventScene, Title, TextCutsceneScene에 적용했습니다.
- 기존 씬 편집 위치를 마이그레이션 시 강제로 옮기지 않았습니다.
- 새 UI는 Canvas Inspector의 대상 목록에 등록해야 합니다. 부모/자식을 중복 등록하지 않는 것이 좋습니다.
- UI끼리 겹침을 자동 해결하는 구조는 아닙니다. 좁은 화면에서 별도 육안 확인이 필요합니다.
- 예전 AbsorbButtonLayoutFix 또는 ResponsiveUISetup을 임의로 다시 실행해 사용자 배치를 덮어쓰지 마세요.
사용법: Docs/UI_직접_편집_사용법.txt
기본 프로젝트의 이전 자동배치 설명 문서는 변경 전 구조 기록입니다. 새 사용법이 최종 기준입니다.

# 화면 크기에 맞춘 UI 배치

전투, PVP, 월드맵, 이벤트, 타이틀, 텍스트 컷신 씬에 적용했습니다. 화면용 Canvas는 1920×1080을 디자인 기준으로 유지하면서 화면 안에 들어오도록 확대·축소합니다. 모바일에서는 노치와 시스템 영역을 제외한 안전 영역을 사용합니다.

Canvas의 `ResponsiveScreenLayout` → **반응형 UI 묶음**에서 대상 UI와 화면 기준점, 여백을 조절합니다. 기준점은 X·Y 각각 0=왼쪽/아래, 0.5=가운데, 1=오른쪽/위입니다. 가장자리 기준이면 여백이며 가운데 기준이면 중심에서 이동하는 거리입니다. 수치는 1920×1080 기준 UI 좌표입니다.

플레이어 HUD는 왼쪽 아래, 상대 HUD는 오른쪽 위, 행동 버튼은 오른쪽, 대화창은 아래쪽 가운데에 배치됩니다. 화면 크기나 안전 영역이 바뀌면 다시 계산합니다. 툴팁은 `ScreenBoundedPopup`이 기존 표시 위치를 화면 안으로 보정합니다.

기존 UI 내부의 버튼 연결과 구조는 유지합니다. 새로운 UI를 추가하거나 그룹의 디자인 크기를 크게 변경할 경우 해당 묶음의 콘텐츠 영역을 다시 등록해야 합니다. `ResponsiveUISetup.Run`은 6개 씬을 저장하는 개발용 설치 함수이므로 수동 배치 작업 중에는 실행하지 마세요.

전면 글리치·플래시·입력 차단막은 전체 화면을 덮고, 기물이나 노드를 따라가는 월드 공간 UI는 원래 위치 계산을 유지합니다. 모바일 화면 방향 설정은 기존 가로 방향을 유지했습니다. 세로 화면에서도 화면 경계 검사는 했지만 세로 전용 UI 디자인이나 실제 기기 조작성 검증을 의미하지 않습니다.

검증: 저장된 6개 씬의 74개 묶음에 대해 1920×1080, 1280×720, 1024×768, 2557×1599, 2560×1080, 2340×1080, 1080×2340 화면 영역 검사를 수행했습니다. 2340×1080에서는 양쪽 노치 여백과 하단 안전 영역을 모의 적용했습니다. 실제 PC 빌드 및 모바일 기기 확인은 별도로 필요합니다.

월드맵·이벤트 씬의 상단 타이머, 골드, 아이템 바는 RunStatusHUD 한 묶음으로 배치합니다. 장식선이 이어지는 원래 크기와 상대 간격을 보존하며, 개별 요소를 별도의 반응형 대상으로 중복 등록하지 않습니다.

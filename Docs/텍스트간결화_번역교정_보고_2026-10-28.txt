DEVORYA 텍스트 간결화 번역 교정 보고

작업 브랜치: codex/text-guide-v2-continue
기존 작업을 유지한 번역 교정만 수행. 커밋 및 다른 개발 브랜치 병합 없음.

변경 요약
- 능력봉인 저항 I/II/III 설명·동적 형식 6개 KR 키: [능력봉인]를 → [능력봉인]을.
- 각성열매 1개 KR 키: 같은 조사 교정.
- 흡수 방어 설명·툴팁 2개 키: EN Final Absorption / JA フィニッシュ吸収.
  KR은 지정된 최종 문구와 이미 일치하여 그대로 유지.
- 바이러스 1개 KR 키: 대상 선정과 각 대상 효과 추첨이 구별되도록 지정된 문구 적용.
- 총 10키, 확인·적용한 언어 항목 14개 중 실제 문구 변경은 12개.
- 한국어 데이터 5개 에셋의 8필드 동기화. 흡수 방어의 한국어 기본 문구도 일치 확인.
- 확률·대상 수·지속시간·비용·전투 로직·씬·프리팹·GUID·Inspector 설정 변경 없음.
- 복제·증식 기획 및 문구는 변경하지 않음.

적용 방법
TooltipTranslationImport.RunGuideV2Corrections 진입점으로 교정 대상 14개 항목만 처리.
원본 문구가 검토된 이전 값과 다르면 중단하는 검사를 통과한 후 적용.
이전 전체 번역 가져오기 Run/RunGuideV2는 실행하지 않음.
흡수 방어 의미 구간의 텍스트만 새 EN/JA 용어에 맞추고 Positive 역할 유지.
그 밖의 의미 구간·역할 및 {percent} 치환 변수 유지.
런타임 번역 SSOT는 기존 Localization String Table이며 별도 런타임 번역 저장소 없음.

검증 결과
Unity 6000.4.0f1 컴파일 오류 0.
TOOLTIP_IMPORT_PASS entries=14 fallbackFields=8.
53개 데이터 × KR/EN/JA = 159개 툴팁 Play Mode 검사 통과.
동적 확률 치환, 제목/본문/섹션 표시, 본문·섹션 넘침, 닫기 검사 통과.
유물 카드 4종 × 3언어 = 12회 등장 연출·LightSurface·번역·텍스트 넘침 검사 통과.
DarkSurface/LightSurface 7개 의미 역할 색상 및 태그 검사 통과.
TOOLTIP_LOCALE_PASS ko/en/ja 및 TOOLTIP_STYLE_PLAYMODE_PASS 확인.
수정 대상이 포함된 5개 테이블의 246개 항목 대조: 지정 항목 외 문구 불변.
그 외 Localization 테이블 및 Shared Data 파일은 교정 전과 바이트 단위로 동일.
지정 항목의 저장된 의미 구간·역할, 한국어 fallback, Localization ID 보존 확인.
공통 TooltipStylePalette.asset은 교정 전과 바이트 단위로 동일.
데이터 에셋은 설명·툴팁 형식 외 필드 불변 확인.
Unity 저장 시 자동 추가된 기존 기본값 필드 및 테스트 폰트 캐시는 교정 전 상태로 복원.
전체 전투 플레이와 모바일 실기기 테스트는 이번 번역 교정 검증 범위에 포함하지 않음.

2. 색상 관리와 적용
공통 에셋: Assets/Resources/TooltipStylePalette.asset
코드: Assets/Scripts/UI/ToolTip/TooltipStylePalette.cs
DarkSurface: 기존 title/body/secondary/positive/negative/value/pieceType 필드 및 색상 유지.
LightSurface: 같은 에셋에 lightTitle/lightBody/lightSecondary/lightPositive/lightNegative/lightValue/lightPieceType 추가.
제목·본문 #1F1F1F / 보조 #666666 / 긍정 #2F7F8D / 부정 #A64F43 / 수치 #8A6A00 / 기물 #70599C.
TooltipTextStyle.Apply/Format의 선택적 surface 인수 기본값은 DarkSurface입니다.
흰 배경 RelicRewardCardUI의 제목/설명만 LightSurface를 명시적으로 선택합니다.
기존 단순 색 반전은 제거했고, Localization의 의미 메타데이터도 선택한 Surface 색상을 사용합니다.
다른 밝은 UI에 자동 적용하지 않으며 유물별 색상 설정이나 문자열 자동 추론은 추가하지 않았습니다.
확률/수치/상태효과/기물 타입은 번역 항목에 지정된 의미 구간만 강조합니다.

3. 중요한 조건을 유지한 항목
- 빠른 발걸음·잔류 추진 제어기: 추가 이동으로 공격 불가.
- 파란색/초록색 점액 파편: 킹 사용 불가, 초록색의 변형 후 상태 부여 순서. 기존 문구 유지.
- 흡수 과충전: 다음 자기 턴 동안 최대 에너지 +1, 중첩 불가. bool 기반 예약/활성 상태 확인.
- 초기 가속: 변형하지 않은 데보리아 폰, 첫 이동, 앞으로 2칸 유지. 일반적인 빈 경로 설명만 제거.
- 회피: 50%, 인접한 빈칸, 공격자가 회피 전 칸으로 이동 유지. 성공 후 소모를 '1회'로 표현.
- 방어·돌파: 실제 성공 시 1회 소모 확인. 상태 해제의 반복 설명 제거.
- 공간이동: 자기 진영 턴 종료 시 이동 성공 후 소모하므로 '1회'로 간결화.
- 퇴화: 공격/흡수 제거 조건, 동일 진영 젤루 폰 1개, 인접 빈칸, 특성 계승 유지.
- 바이러스: 최대 3개 무작위 대상, 대상마다 두 효과 중 하나를 독립적으로 선택한다는 정보 유지.
  지시서 예시보다 '각각/중 하나'를 남겨 두 효과 동시 적용으로 오해하지 않도록 했습니다.
  지속시간·확률·파티클·비용·저항 로직은 수정하지 않았습니다.
- 합성·분열·합성: 강화: 재료 수/생성 위치/종족 유지/특성 계승/지속시간이 핵심이므로 기존 문구 유지.
- 젤루 벽·흡수의 여운·간파·확률 자세 등 이미 짧은 문구는 유지.

4. 확인 필요하여 수정하지 않은 항목
복제(unique_skill.jellu_clone.description):
PieceManager.ClonePieceTo는 타입·진영·이동 허용·능력·종족 태그·PieceData·흡수 외형을 복사합니다.
현재 특성 및 상태효과 전체 복사 호출은 없습니다. '자신을 복제'가 모든 정보를 복사한다는 의미로
받아들여질 수 있으므로 기존 3개 언어 문구와 동작을 유지했습니다. 복사 범위 기획 확인 필요.
증식(unique_skill.jellu_multiply.description):
설명은 '같은 종족'이나 UseJelluMultiply → SpawnJelluPawnFromSource → SpawnJelluPawn은
'Jellu Pawn' 데이터를 사용합니다. 다른 종족이 능력을 사용하는 경우 설명과 불일치 가능성이 있습니다.
지시서의 불확실한 항목 보류 원칙에 따라 번역/동작 모두 유지했습니다.
이 두 항목은 미해결 확인 사항이며 이번 작업에서 해결한 것으로 간주하지 않습니다.
기존 미연결/구형 Localization 별칭 및 테스트 아이템의 문구는 사용처 확인 없이 일괄 변경하지 않았습니다.

1. 전체 상태효과 분류
None(없음): 효과 없음, 변경 제외.
공간이동(Teleport): 턴 종료 발동형 → 이동 및 Born 연출 성공 후 소모.
방어(Defence): 피격 발동형 → 실제 공격을 막고 튕겨내는 처리 후 소모.
회피(Evasion): 피격 확률 발동형 → 실제 회피 이동 및 공격 연출 완료 후 소모.
돌파(Breakthrough): 공격 조건 발동형 → 상대 방어를 실제로 무시해 공격/흡수에 성공한 후 소모.
공격불가(AttackDisabled): 지속형 제한 → 기존 규칙 유지.
이동불가(MoveDisabled): 지속형 제한 → 기존 규칙 유지.
행동불가(ActionDisabled): 지속형 제한 → 기존 규칙 유지.
능력봉인(AbilitySealed): 지속형 제한 → 기존 규칙 유지.
호위(Taunt): 현재 코드상 상태 유지 중 반복해서 인접 아군 대신 피격 가능한 보호 효과. 반복성을 임의로 바꾸지 않고 제외.
퇴화(Degeneration): 사망 확정 시 원본 제거 및 폰 생성 처리. 원본이 제거되어 반복 발동하지 않는 구조이므로 별도 제거 변경 없이 보존.
등록된 별도의 지속형 강화 패시브 상태는 위 목록 외에는 없습니다. 특성(방어 자세/회피 자세/흡수 방어 등)은 상태효과와 별개이며 소모 대상이 아닙니다.

2. 제거 시점과 조건
공간이동: Select → Fade Out → 실제 좌표/그리드 이동 확인 → Born/Idle → RemoveStatusEffect(Teleport).
목적지 없음, 이동 전 취소, 이동 불성립이면 제거하지 않습니다. 대상 하나 완료 후 다음 대상으로 진행합니다.
기존 기물 객체, 특성, 다른 상태, 순차 목적지 선택, 입력 잠금 및 턴 전환을 유지합니다.
현재 능력의 공간이동은 자신에게 부여되므로 자기 턴 종료에 발동 기회를 얻은 뒤 다음 자기 턴의 감소가 일어납니다.
빈 공간이 없으면 기존 기간 안에서 유지/만료하며 실패를 이유로 기간을 연장하지 않습니다.

방어: 실제 방어 분기의 PlayPieceBlockedAttackMoveAnimation 종료 후 제거.
흡수 방어 특성이 막은 경우에는 방어 상태가 대신 소모되지 않습니다.

회피: PlayEvadedAttack 종료 후 선택한 탈출 좌표에 같은 기물이 등록되었는지 확인하고 제거.
50% 판정 실패, 탈출 공간 없음, 간파 취소 시 소모하지 않습니다.
방어와 함께 있을 때 회피가 성공하면 회피만 소모합니다. 회피 실패 후 방어 성공이면 방어만 소모합니다.

돌파: 상대 방어가 존재하고, 마지막 적 자동 방어 무시가 아닌 상황이며, 흡수 방어에 막히지 않은 실제 방어 우회인지를 기록합니다.
그 공격의 포획/흡수 성공 처리와 이동 연출이 끝난 후 돌파를 제거합니다.
방어 없는 적 공격, 일반 이동, 회피로 빗나간 공격, 흡수 방어에 막힌 공격에서는 유지합니다.
마지막 적 자동 방어 무시가 이미 적용되는 경우 돌파는 사용되지 않은 것으로 처리합니다.

3. 공통 지속시간/재부여
Piece.RemoveStatusEffect의 기존 API를 재사용했습니다. 새 enum, 분류 필드, 매니저, 직렬화 필드는 없습니다.
이 API는 상태 제거 시 아이콘을 갱신하고 없는 상태를 다시 제거하면 false를 반환합니다.
ReduceStatusEffectTurns, 상태 데이터 기본 지속시간, AddStatusEffect의 저항/재부여/중첩 계산을 바꾸지 않았습니다.
이번 대상의 현재 최대 중첩은 1이며, 기존 제거 API처럼 해당 종류의 상태를 제거합니다.
상태 부여/조회/AI 후보 생성 과정에는 소모 처리를 넣지 않았습니다.
바이러스의 각 대상별 50:50 선택, 선택 효과만 저항 판정, 전용 지속시간 2는 그대로 유지했습니다.

4. 간파 처리 기준

8. 남은 확인 및 한계

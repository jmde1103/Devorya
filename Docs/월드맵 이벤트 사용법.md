# 월드맵 이벤트 사용법

씬 전환 데이터의 **월드맵 이벤트 데이터 (선택)**에 실행할 에셋을 연결합니다. 다음 월드맵 진입 시 초기화와 시작 카메라 연출이 끝난 뒤 한 번만 실행되며, 실행 시작 전에 대기 참조를 제거합니다. 이후 단순 복귀 시에는 반복되지 않습니다.

데이터 위치: `Assets/Devorya/Data/Event/WorldMapEvents`

- **월드맵_기본 이벤트**: 실제 작업용 빈 데이터.
- **월드맵_연출 예제**: 조작 잠금 → UI 숨김 → 대화 → 글리치 → 조명·반짝임 → UI 표시 → 조작 해제 예제. 기본 씬에는 연결하지 않았습니다.
- 새 데이터 생성: Project 창의 `Create > Devorya > 월드맵 > 이벤트 데이터`.

## 스텝

1. **대화 출력**: 아래 `Event Dialogue Localization > Dialogue Pages`에서 페이지를 작성합니다. 기존 대화 UI의 타이핑과 클릭 진행을 사용하며 대화 중에는 월드맵 조작이 임시 잠깁니다.
2. **플레이어 조작 잠금·해제**: 체크하면 노드 선택, 카메라 드래그·확대 및 연결된 HUD 조작을 잠급니다. 체크를 끄면 해제합니다. 이미 시작한 자동 이동이나 씬 전환을 취소하는 기능은 아닙니다.
3. **UI 숨김·표시**: 관리자의 ‘숨김·잠금 대상 UI’를 제어합니다. 대화창과 글리치·반짝임 화면은 별도로 유지됩니다.
4. **스크린 글리치**: 기존 글리치 효과를 재사용합니다. 강도, 지속 시간, 완료 대기를 설정합니다.
5. **글로벌 조명·반짝임**: 글로벌 조명의 목표 색상·밝기와 전환 시간을 설정합니다. 화면 반짝임은 색상, 강도, 지속 시간, 횟수, 간격을 설정합니다. 두 효과는 함께 또는 따로 실행할 수 있습니다.
6. **대기**: 다음 스텝까지 기다릴 시간을 설정합니다.

‘완료 대기’를 끄면 다음 스텝과 연출이 동시에 진행됩니다. 이벤트의 마지막에는 진행 중인 연출을 마친 뒤 종료합니다. 시간 설정은 게임의 시간 배율에 영향을 받지 않습니다.

## 종료와 복구

이벤트 종료·중단·컴포넌트 비활성화 시 조작 잠금과 UI는 원래 상태로 복구됩니다. 조명도 기본적으로 복구되며, 데이터의 ‘종료 시 조명 복원’을 끄면 정상 종료 시 마지막 조명 상태를 유지합니다. 이후 낮밤 전환은 기존 관리자가 다시 담당합니다. 중단 시에는 조명이 항상 복구됩니다.

Hierarchy의 관리자는 자동 실행용 기본 데이터를 사용하지 않습니다. 수동 테스트용 데이터를 연결한 뒤 다른 UnityEvent에서 관리자의 `PlayEvent()`를 호출할 수도 있습니다. 코드에서는 `Play(WorldMapEventData)`로 다른 데이터를 실행할 수 있습니다. Play Mode의 컴포넌트 메뉴에서 ‘이벤트 실행’ 또는 ‘이벤트 중단·복원’을 사용할 수 있습니다.

새 UI를 추가하면 관리자의 ‘숨김·잠금 대상 UI’ 목록에 해당 CanvasGroup을 연결합니다. 대화 UI 또는 이벤트 관리자 자신을 포함하는 상위 UI는 넣지 않습니다.

## 배틀·이벤트 씬과 같은 편집 순서

1. 월드맵 이벤트 데이터 에셋을 선택합니다. `Event Steps`에서 +/− 버튼으로 스텝을 추가·삭제하고 왼쪽 핸들을 드래그해 순서를 바꿉니다.
2. `Step01 - 이름`을 펼쳐 스텝 이름과 종류를 설정합니다. 선택한 종류의 설정만 표시됩니다. 위·아래의 `전체 펼치기 / 전체 접기`로 목록을 관리합니다.
3. `Duplicate Step Below (바로 아래 복제)`는 해당 스텝을 바로 아래에 복제합니다. 대화의 한국어와 기존 영어·일본어 번역도 복사하며 복사본은 독립적인 번역 키를 사용합니다.
4. 대화는 아래 `Event Dialogue Localization > Dialogue Pages` 영역에서 작성합니다. 페이지별 한국어 입력, ▲/▼ 순서 변경, 삭제, 페이지 추가를 지원합니다.
5. `Localization 생성 / 한국어 동기화`를 누르면 `WorldMap_Dialogue` 테이블에 한국어를 반영합니다. 생성된 English / Japanese 입력란에서 번역을 작성합니다. 기존 번역은 동기화로 덮어쓰지 않습니다. 한국어를 고친 뒤에는 동기화를 다시 실행합니다.
6. 하단에서 번역 작성 현황을 확인하고 `Localization Tables 열기`로 기존 테이블 창을 열 수 있습니다.

에셋 GUID와 페이지 고정 ID를 키에 사용하므로 스텝·페이지 순서나 데이터 이름을 바꿔도 번역 연결이 유지됩니다. 기존에 직접 연결한 LocalizedString도 그대로 읽으며, 동기화 시 원래 번역 값을 새 키로 복사합니다. 페이지나 스텝을 삭제해도 번역 테이블 항목은 자동 삭제하지 않아 Undo 복원과 다른 참조를 보호합니다.

기존 월드맵 데이터나 씬 연결을 교체할 필요는 없습니다. 기존 배틀·이벤트 씬 에디터는 변경하지 않았으며, 월드맵의 지원 스텝 종류는 대화·조작 잠금·UI 표시·글리치·조명·대기로 유지합니다.
## 씬 전환 시 월드맵 이벤트 전달

- 배틀 이벤트 `EventSequenceData`: 완료 설정의 `월드맵 이벤트 데이터 (선택)`. WorldMap, LoadScene, BattleWin 완료 경로에서 전달합니다.
- 이벤트 씬 `EventSceneData`: Completion의 같은 항목. WorldMap 또는 LoadScene 완료 시 전달합니다.
- 이벤트 씬 `StartBattle` 스텝: 스텝의 같은 항목. 전투를 거쳐 다음 월드맵에 도착했을 때 실행합니다.
- `StageBattleData`: 승리 후 전환 설정의 같은 항목. 보상 정산 이후 전환 시 전달합니다.
- `TextCutsceneData`: 다음 씬 설정의 같은 항목. 컷씬에서 이벤트 씬·전투 씬을 더 거쳐도 다음 월드맵까지 보관합니다.
- 일반 `SceneChanger` 버튼 및 `ShopController`의 상점 나가기: 각 컴포넌트의 같은 항목을 사용할 수 있습니다.

모든 항목은 선택 사항입니다. 아무 데이터도 예약되지 않은 상태에서 비워 두면 이벤트 없이 기존 흐름으로 이동합니다. 앞선 전환에서 받은 예약이 있으면, 중간 전환의 빈 항목은 예약을 지우지 않습니다. 새 데이터가 지정된 경우에는 가장 최근에 지정된 데이터 한 개로 교체합니다. 이벤트 에셋 자체를 삭제하는 것은 아니며 대기 참조만 비웁니다.

새 런 또는 런 초기화에서는 남은 예약을 제거합니다. 예약은 실행 중 메모리에서만 유지되며 게임 종료 후 저장·복구하는 기능은 아닙니다. 코드에서는 `WorldMapEventRuntimeState.Queue(data)`로 예약하고 `Clear()`로 취소할 수 있습니다.

UI 직접 편집 사용법 (새 방식)

작업 경로: C:\Users\zntif\.codex\worktrees\status-effect-restrictions\Devorya

1. 플레이를 종료한 상태에서 씬을 엽니다.
2. UI 또는 UI 묶음의 RectTransform을 직접 이동하거나 크기를 변경합니다.
3. 씬을 저장합니다. Canvas의 ResponsiveScreenLayout에 배치가 자동 기록됩니다.
4. 플레이하여 확인합니다. 저장 전에도 플레이 직전에 현재 편집 배치를 기록합니다.

화면 비율이 바뀌면 UI 전체 표시 영역의 중심이 차지하던 상대 위치를 유지합니다.
너무 가장자리에 있어 화면 밖으로 나가면 안쪽으로 보정하며, 화면보다 큰 묶음은 축소합니다.
여러 UI가 서로 겹치지 않도록 재정렬하는 기능은 아닙니다. 좁은 화면에서는 겹침 확인이 필요합니다.

Canvas Inspector:
- '씬에서 편집한 배치 사용'이 켜져 있어야 합니다.
- 등록된 대상 UI를 편집합니다. 묶음의 자식도 기존 Unity 방식대로 편집할 수 있습니다.
- 완전히 새 HUD를 추가했다면 '대상 UI 추가'에 그 묶음의 RectTransform을 지정합니다.
- 부모와 자식을 동시에 별도 대상으로 중복 등록하지 마세요.
- '현재 씬 배치 기록' 버튼으로 수동 기록도 가능합니다.
- 기존 anchor/inset/relativeTo/relativeOffset은 새 방식에서 사용하지 않습니다.
- 마무리 흡수 버튼의 위치도 씬에서 직접 편집할 수 있습니다.
- 위치 변경을 영구 보존하려면 플레이 종료 후 편집 모드에서 씬을 저장해야 합니다.

SceneUILayoutAuthoring.cs가 씬 저장 및 플레이 직전의 기록을 담당합니다.
ResponsiveScreenLayout.cs가 실행 중 화면 비율/안전 영역 변화에 맞게 배치합니다.
현재 배치 기록은 편집 시 Canvas 크기를 기준으로 합니다. 원하는 Game View 비율에서 배치한 뒤 저장하세요.
서로 다른 프로젝트 경로에는 변경이 자동 전파되지 않습니다. 위 작업 경로인지 확인하세요.

이 문서는 이전 UI_위치_자동배치_구조와_수정_가이드.txt의 기존 고정 배치 방식 설명을 대체하는 새 사용법입니다.
